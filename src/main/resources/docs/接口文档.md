# 接口文档

## 1. 接口概述

### 1.1 基础信息
- **基础路径**: 未配置（根据实际部署配置）
- **认证方式**: Token 认证（通过 AuthTokenService 生成）
- **数据格式**: JSON
- **字符编码**: UTF-8

### 1.2 统一响应格式
所有接口返回统一使用 Result 对象封装：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

#### 响应字段说明
| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码 |
| message | String | 响应消息 |
| data | Object | 响应数据 |

#### 状态码说明
| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 500 | 服务器内部错误 |

## 2. 认证接口

### 2.1 用户注册

**接口信息**
- **接口路径**: `/auth/register`
- **请求方法**: POST
- **权限要求**: 公开接口（无需登录）
- **请求参数类型**: application/x-www-form-urlencoded

**请求参数**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |

**请求示例**
```bash
POST /auth/register?username=testuser&password=123456
```

**响应示例**
```json
{
  "code": 200,
  "message": "",
  "data": null
}
```

**错误响应**
```json
{
  "code": 500,
  "message": "用户名已存在，请使用其他用户名",
  "data": null
}
```

---

### 2.2 用户登录

**接口信息**
- **接口路径**: `/auth/login`
- **请求方法**: POST
- **权限要求**: 公开接口（无需登录）
- **请求参数类型**: application/x-www-form-urlencoded

**请求参数**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |

**请求示例**
```bash
POST /auth/login?username=admin&password=123456
```

**响应示例**
```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**说明**
- 登录成功后，`data` 字段返回 JWT Token
- 后续请求需要在请求头或参数中携带该 Token

**错误响应**
```json
{
  "code": 500,
  "message": "用户名或密码错误",
  "data": null
}
```

## 3. 权限管理接口

### 3.1 修改用户等级

**接口信息**
- **接口路径**: `/auth/level/modify`
- **请求方法**: POST
- **权限要求**: Level 1（超级管理员）
- **请求参数类型**: application/x-www-form-urlencoded

**请求参数**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 要修改的用户名 |
| level | Integer | 是 | 目标等级 |

**请求示例**
```bash
POST /auth/level/modify?username=testuser&level=3
```

**响应示例**
```json
{
  "code": 200,
  "message": "等级修改成功",
  "data": null
}
```

**错误响应**
```json
{
  "code": 500,
  "message": "无法修改等级大于等于自己的用户",
  "data": null
}
```

**权限规则**
- 只能修改等级低于自己的用户
- 不能将用户等级修改为大于等于自己的等级

---

### 3.2 修改用户密码

**接口信息**
- **接口路径**: `/auth/password/modify`
- **请求方法**: POST
- **权限要求**: Level 1, 2（超级管理员、管理员）
- **请求参数类型**: application/x-www-form-urlencoded

**请求参数**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 要修改密码的用户名 |
| password | String | 是 | 新密码 |

**请求示例**
```bash
POST /auth/password/modify?username=testuser&password=newpassword123
```

**响应示例**
```json
{
  "code": 200,
  "message": "密码修改成功",
  "data": null
}
```

**约束条件**
- 密码长度不能少于 6 位
- 只能修改等级低于自己的用户密码

## 4. 接口等级配置接口

### 4.1 查询所有接口配置

**接口信息**
- **接口路径**: `/api/level/interfaces`
- **请求方法**: GET
- **权限要求**: Level 1（超级管理员）

**请求参数**: 无

**请求示例**
```bash
GET /api/level/interfaces
```

**响应示例**
```json
{
  "code": 200,
  "message": "",
  "data": [
    {
      "id": 1,
      "interfacePath": "/api/level/interfaces",
      "interfaceMethod": "GET",
      "allowedLevels": "1",
      "description": "查询所有接口等级配置",
      "status": 1
    }
  ]
}
```

---

### 4.2 查询单个接口配置

**接口信息**
- **接口路径**: `/api/level/interface/{id}`
- **请求方法**: GET
- **权限要求**: Level 1（超级管理员）

**请求参数**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 配置 ID（路径参数） |

**请求示例**
```bash
GET /api/level/interface/1
```

**响应示例**
```json
{
  "code": 200,
  "message": "",
  "data": {
    "id": 1,
    "interfacePath": "/api/level/interfaces",
    "interfaceMethod": "GET",
    "allowedLevels": "1",
    "description": "查询所有接口等级配置",
    "status": 1
  }
}
```

**错误响应**
```json
{
  "code": 500,
  "message": "接口等级配置不存在",
  "data": null
}
```

---

### 4.3 创建接口配置

**接口信息**
- **接口路径**: `/api/level/interface`
- **请求方法**: POST
- **权限要求**: Level 1（超级管理员）
- **请求参数类型**: application/json

**请求参数**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| interfacePath | String | 是 | 接口路径 |
| interfaceMethod | String | 是 | HTTP 方法 |
| allowedLevels | String | 是 | 允许的等级列表（逗号分隔） |
| description | String | 否 | 描述信息 |
| status | Integer | 否 | 状态：1-启用，0-禁用（默认 1） |

**请求示例**
```bash
POST /api/level/interface
Content-Type: application/json

{
  "interfacePath": "/api/user/**",
  "interfaceMethod": "GET",
  "allowedLevels": "1,2,3",
  "description": "用户查询接口",
  "status": 1
}
```

**响应示例**
```json
{
  "code": 200,
  "message": "创建成功",
  "data": null
}
```

---

- **接口路径**: `/api/level/interface`

- **权限要求**: Level 1（超级管理员）

**请求示例**

```json
{
  "code": 200,
  "message": "更新成功",
  "data": null
}
```

## 5. 错误码汇总

| 错误信息 | 说明 |
|----------|------|
| 用户名不能为空 | 注册或登录时用户名为空 |
| 密码不能为空 | 注册或登录时密码为空 |
| 用户名已存在，请使用其他用户名 | 注册时用户名重复 |
| 用户名或密码错误 | 登录时凭证错误 |
| 未登录或登录已过期 | Token 无效或过期 |
| 要修改的用户不存在 | 修改等级/密码时用户不存在 |
| 无法修改等级大于等于自己的用户 | 违反等级修改规则 |
| 无法将用户等级修改为大于等于自己的等级 | 违反等级修改规则 |
| 密码长度不能少于 6 位 | 修改密码时密码太短 |
| 接口等级配置不存在 | 查询/更新/删除不存在的配置 |

## 6. 接口权限配置示例

### 6.1 配置说明
接口权限通过 `interface_level` 表配置，配置后系统会自动拦截并验证。

### 6.2 配置示例

**示例 1: 只允许超级管理员访问**
```json
{
  "interfacePath": "/api/admin/**",
  "interfaceMethod": "GET",
  "allowedLevels": "1",
  "description": "管理员专用接口"
}
```

**示例 2: 允许管理员和普通管理员访问**
```json
{
  "interfacePath": "/api/user/list",
  "interfaceMethod": "GET",
  "allowedLevels": "1,2,3",
  "description": "用户列表查询"
}
```

**示例 3: 支持通配符**
```json
{
  "interfacePath": "/api/user/**",
  "interfaceMethod": "GET",
  "allowedLevels": "1,2,3",
  "description": "所有用户查询接口"
}
```
